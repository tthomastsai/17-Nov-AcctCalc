# AI 使用證據卡（草稿）

> 這份是依開發對話整理的事實紀錄，繳交前請自己核對、改成自己的話，並補上「待補」的部分。

- **使用工具**：Claude（對話式 AI 代理）
- **我的角色**：提出需求、提供實機照片與功能說明卡、驗收每一版並退回或要求修改
- **AI 的角色**：撰寫程式、打包 APK、截圖與自動測試

## 一、我提供的依據

| 依據 | 用途 |
|---|---|
| 實機照片（正面） | 按鍵配置、配色、螢幕位置 |
| 包裝背面的功能說明卡 | 運算規則與顯示格式（小數點、千分位、超位、常數計算、%、M+/M−） |
| 螢幕全亮的特寫照片 | 指示列文字 MINUS／MEMORY／ERROR／GRAND TOTAL 與運算符號位置 |
| 自己按實機的結果 | GT 連按、AC 清除範圍等說明卡沒寫的行為 |

## 二、採用、修改、退回

| AI 的做法 | 我的決定 | 理由 |
|---|---|---|
| 依照片排出 5×6 按鍵、灰色數字鍵、黃色 AC／ON 鍵 | 採用 | 與實機一致 |
| 字型 Anthropic Sans | 修改 → Google Sans | AI 回報取不到 Anthropic Sans 字型檔 |
| 畫出機身的曲線外形 | 退回 | （待補理由） |
| 螢幕用七段顯示器字型 | 退回 → 一般字型 | （待補理由） |
| 負號一律放在數字前 | 修改 | 實機在 12 位數全滿時，負號顯示在上方指示列 |
| 顯示與運算細節（AI 原本的猜測） | 修改 | 依功能說明卡：整數帶小數點、`'` 千分位、`E 1.09728394063` 超位、CE 保留數字、`5 ÷ = = = =` → 0.0016 |
| 指示列只有 M／E／GT 縮寫 | 修改 | 依實機螢幕：印出四個英文標示，運算符號放右上 |
| 用網頁技術包成 App（WebView） | 修改 → 純原生 | 我看建置指令覺得像 PWA，追問後確認是 WebView 外殼，於是要求改成原生，並保留原本的奶油質感 |
| GT 只有叫出功能 | 修改 | 實機 GT 連按第二下會清空 GT |
| GT 第三下叫出清空後的 0 | 退回 | 實機不會這樣 |
| AC 不清除 M | 修改 | 實機 AC 會同時清空 GT 與 M |
| 保留 OFF 鍵 | 修改 → 設定鍵 | 手機不需要關機鍵 |
| — | 我新增的需求 | 按鍵高度、主題配色、機身位置（偏上／置中／偏下）、English (UK) |
